ROM (Read Only Memory) হলো এমন এক ধরনের মেমোরি যেখানে ডাটা স্থায়ীভাবে সংরক্ষিত থাকে এবং সাধারণ অবস্থায় ব্যবহারকারী এটি পরিবর্তন করতে পারে না।

সহজভাবে বললে,
ROM হলো কম্পিউটারের এমন একটি মেমোরি যেখানে কম্পিউটার চালু হওয়ার জন্য প্রয়োজনীয় মৌলিক নির্দেশনা আগে থেকেই সংরক্ষিত থাকে।

ROM-এর প্রধান বৈশিষ্ট্য:
স্থায়ী মেমোরি → কম্পিউটার বন্ধ হলেও এর ডাটা মুছে যায় না
শুধু পড়া যায় → সাধারণত এতে সংরক্ষিত ডাটা পরিবর্তন করা যায় না
কম্পিউটার চালু করার জন্য প্রয়োজনীয় তথ্য রাখে
ROM-এ কী থাকে?

সাধারণত ROM-এ BIOS/UEFI এর মতো firmware থাকে।

যখন তুমি কম্পিউটার অন করো:

CPU প্রথমে ROM থেকে নির্দেশনা পড়ে
BIOS/UEFI চালু হয়
হার্ডওয়্যার চেক করে
তারপর Operating System লোড করে
RAM আর ROM-এর পার্থক্য

RAM

অস্থায়ী মেমোরি
কম্পিউটার বন্ধ হলে ডাটা মুছে যায়
কাজ করার সময় ব্যবহৃত হয়

ROM

স্থায়ী মেমোরি
কম্পিউটার বন্ধ হলেও ডাটা থাকে
স্টার্টআপ নির্দেশনা সংরক্ষণ করে
সহজ উদাহরণ

ধরো,

ROM = রান্নার বই 📖
RAM = রান্নাঘরের কাজের টেবিল 🍳

বইতে নির্দেশনা স্থায়ীভাবে লেখা থাকে
টেবিলে কাজ চলাকালীন জিনিস রাখা হয়

কম্পিউটারেও একইভাবে:

ROM নির্দেশনা ধরে রাখে
RAM সাময়িকভাবে কাজ করে
